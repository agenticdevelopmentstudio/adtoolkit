## Project Summary

`agenticdevelopertoolkit` is a set of reusable per-platform packages for agentic apps: the shared web libraries (`ui`, `chat`, `themes`, `markdown`, `search`, `editing`, …) beside the adh app platform and its feature packages; a workspace of Xcode projects for Apple (the multi-platform `AgenticDeveloperToolkit` frameworks, the macOS-first `AgenticToolkit` product frameworks, the `AgenticToolkitApp` host and the `AIPlugins` bundles); and a Python package for Terminal. It absorbed the former `agentictoolkit` repo, history included.

## Type & Tech Stack

- **Type:** multi-platform library toolkit
- **Web:** TypeScript + React 19 + Tailwind v4, one pnpm workspace at `packages/web/`
- **Apple:** Swift 6.3, Xcode projects generated by XcodeGen from `project.yml`, wired by `packages/apple/agenticdevelopertoolkit.xcworkspace`
- **Terminal:** Python (`packages/terminal/pyproject.toml`)
- **Android / Windows:** port plans in `docs/planning/ports/`

## Key Files & Components

- `install.sh` — regenerates every Xcode project, then installs and builds the web workspace
- `packages/web/packages/chat/` — chat UI and `PersonaChatBackend`
- `packages/web/packages/persona/` — the consumer crossing for the persona vocabulary
- `packages/apple/AgenticDeveloperToolkit/` — multi-platform core, UI and theme model
- `packages/apple/AgenticToolkit/project.yml` — the product frameworks and their aggregate targets
- `packages/apple/AIPlugins/` — `.aiplugin` bundles that link the toolkit frameworks without embedding them
- `tools/` — `check_doc_links.py`, `check_boundaries.py` and the other guards CI runs

## Build & Test Commands

```bash
./install.sh
cd packages/web && pnpm build && pnpm test && pnpm lint
cd packages/terminal && pip install -e . && pytest
xcodebuild -workspace packages/apple/agenticdevelopertoolkit.xcworkspace \
  -scheme AgenticToolkitMacOSTestsAll -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath ~/Library/Developer/Xcode/DerivedData/agenticdevelopertoolkit-managed \
  -skipPackagePluginValidation -skipMacroValidation build
```
