
Construction options:

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `text` | `String` | — (required) | Text rendered as the badge's label |
| `color` | Color | — (required) | The badge's tint; controls the background (filled) or border and text (outlined) |
| `style` | Style | filled | Visual treatment: filled (solid background) or outlined (bordered) |

Two styles are available: filled and outlined, with filled as the default.
Beyond construction, the component exposes one operation: restyling it in
place with new text, color, and style.
