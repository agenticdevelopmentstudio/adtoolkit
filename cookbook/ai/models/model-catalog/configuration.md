
| Option | Type | Default | Description |
|--------|------|---------|-------------|
| resource location | platform resource reference | the framework's own bundled resource location | Passed when loading the catalog; the location to read `model-catalog.json` from. Tests override it to simulate a missing resource. |
| `model-catalog.json` | bundled resource | the framework's bundled `model-catalog.json` resource | Fixed resource filename, not configurable per call. Regenerated by the catalog-generation tooling; never hand-edited. |
| `schemaVersion` | integer | `0` for the empty fallback catalog; `1` in the shipped resource | Carried on the payload and on the catalog's private empty construction path; not validated at load time (see `schema-version-not-gated`). |
| `models`, `offerings` | list of model entries; per-gateway map of offering records | `[]`, `[:]` | Constructor parameters for building a catalog directly, bypassing resource loading entirely — the path the test suite's sample catalog and the empty fallback catalog both use. |
