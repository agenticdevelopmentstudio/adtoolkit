
- **class-installed-once-per-context**: Installing the class in a given extension environment MUST return the constructor already cached for that environment, without re-building it, whenever a previously cached constructor object is found there.
- **class-evaluated-on-first-need**: When no cached object exists, installing the class MUST build it fresh in that environment and return the resulting object.
- **class-install-failure-returns-nil-and-logs**: Installing the class MUST return nothing, and MUST log an error naming the environment it was installing into, when building the class produces something other than a usable object — the outcome of the class's own internal construction failing and being converted to a null result.
- **class-caching-write-best-effort**: Caching the built constructor for reuse MUST be attempted separately from building the constructor itself, so that a failure to cache it MUST NOT prevent the constructor from being usable for the installation that just produced it; it only means a later installation in the same environment finds no cached object, builds the class again, and returns a second, distinct constructor function.
- **instance-fields-default-empty**: The `Uri` constructor MUST default `scheme`, `authority`, `path`, `query`, and `fragment` to `''` whenever the corresponding constructor argument is falsy.
- **has-authority-flag**: The `Uri` constructor MUST set its internal authority flag to `true` when the `hasAuthority` argument is truthy, or when `authority` is a non-empty string, and to `false` otherwise.
- **instance-frozen**: Every `Uri` instance MUST be frozen before it is returned to any caller.
- **readonly-accessors**: `scheme`, `authority`, `path`, `query`, `fragment`, and `fsPath` MUST be exposed only as enumerable getter-only properties on `Uri.prototype`, never as writable data properties.
- **fs-path-derivation**: The `fsPath` getter MUST return the percent-decoded `path` — falling back to `path` unchanged when decoding throws on a malformed escape — prefixed with `'//' + authority` when `authority` is non-empty, and MUST return the decoded path alone otherwise.
- **with-overrides-only-given-fields**: `with(change)` MUST replace only the fields present as own keys with a value `!== undefined` in `change` (`scheme`, `authority`, `path`, `query`, `fragment`), leaving every other field equal to the receiver's own value.
- **with-returns-new-instance**: `with(change)` MUST construct and return a new `Uri` instance; it MUST NOT mutate the receiver, which **instance-frozen** already makes impossible.
- **with-authority-promotes-has-authority**: `with(change)` MUST set the result's authority flag to `true` when the receiver's own authority flag is `true`, OR when `change.authority` is present and non-empty, even if the receiver itself had no authority.
- **to-string-default-assembly**: `toString(skipEncoding)` called with no truthy `skipEncoding` MUST return `scheme + ':'` (omitted when `scheme` is `''`) followed by `'//' + authority` only when the authority flag is `true`, followed by `path` unchanged, followed by `'?' + query` only when `query` is non-empty, followed by `'#' + fragment` only when `fragment` is non-empty.
- **to-string-skip-encoding**: `toString(true)` MUST decode `authority`, `path`, `query`, and `fragment` before assembling the string described in **to-string-default-assembly**, for that call's return value only; the instance's own stored fields MUST remain unchanged.
- **to-json-plain-object**: `toJSON()` MUST return a new plain object with own enumerable properties `scheme`, `authority`, `path`, `query`, `fragment`, and `fsPath` (read through the getter), so `JSON.stringify` on a `Uri` instance serializes these six values rather than `{}` — which is what `JSON.stringify` would otherwise produce, since none of a `Uri`'s properties are its own enumerable properties.
- **file-sets-scheme-and-authority**: `Uri.file(path)` MUST construct a `Uri` with `scheme` `'file'`, `authority` `''`, and its authority flag `true` (set explicitly, not inferred from a non-empty `authority`).
- **file-encodes-segments-preserves-slashes**: `Uri.file(path)` MUST percent-encode `path` by splitting on `'/'`, encoding each non-empty segment, and rejoining with `'/'` — so `/` separators survive encoding while every other character in a segment is escaped exactly as component-encoding escapes it.
- **file-ensures-leading-slash**: `Uri.file(path)` MUST prepend a `'/'` to the encoded path when it does not already start with one, so the resulting `path` always begins with `'/'`.
- **parse-splits-components**: Parsing a URI string MUST decompose the string form of the given value into `scheme`, an authority-present flag, `authority`, `path`, `query`, and `fragment`, using a single pattern that captures, in order, an optional `scheme:` prefix, an optional `//authority` block, the remainder up to a `?` or `#`, an optional `?query` block, and an optional `#fragment` block; any group that does not match MUST default to `''`.
- **parse-lowercases-scheme**: `Uri.parse(value, strict)` MUST lower-case the matched scheme before storing it, regardless of the case in `value`.
- **parse-strict-requires-scheme**: `Uri.parse(value, true)` MUST throw a JavaScript `Error` with the message `"Uri.parse: '" + String(value) + "' must contain a scheme when 'strict' is true"` when no scheme was matched, and MUST NOT construct a `Uri` in that case.
- **parse-non-strict-allows-schemeless**: `Uri.parse(value, strict)` MUST construct and return a `Uri` with `scheme` `''` when `strict` is falsy and `value` carries no scheme, taking no throwing path.
- **parse-to-string-round-trips**: For any `Uri` produced by `Uri.parse`, `Uri.parse(original.toString())` MUST reproduce the same `scheme`, `authority`, `path`, `query`, and `fragment` as `original`, whether or not `original` carries an authority.
- **join-path-requires-uri-instance**: `Uri.joinPath(base, ...segments)` MUST throw a `TypeError` with the message `'Uri.joinPath: the base argument must be a vscode.Uri'` when `base` is not an instance of the same `Uri` constructor performing the check, and MUST NOT construct a result in that case.
- **join-path-inserts-separator**: `Uri.joinPath(base, ...segments)` MUST insert exactly one `'/'` between `base`'s `path` and the percent-encoded, `'/'`-joined `segments` when `base`'s `path` is non-empty and does not already end in `'/'`, and MUST NOT insert an additional `'/'` when it already ends in one.
- **join-path-collapses-duplicate-slashes-not-dot-segments**: Joining path segments onto a base MUST collapse any run of two or more consecutive `'/'` characters in the assembled path to a single `'/'`, and MUST NOT resolve `'.'` or `'..'` path segments in the result.
- **join-path-preserves-other-fields**: `Uri.joinPath(base, ...segments)` MUST return a `Uri` whose `scheme`, `authority`, `query`, `fragment`, and authority flag equal `base`'s own, changing only `path`.
- **join-path-empty-appended-is-unchanged**: `Uri.joinPath(base)`, called with no `segments`, MUST return a `Uri` whose `path` equals `base`'s `path` unchanged, because the encoded, joined suffix of zero segments is `''`.
- **class-and-prototype-frozen**: Building the class MUST freeze its prototype and then the constructor itself, after every static and prototype member is attached, within the same build that created them, before caching the constructor or handing it to any caller.
- **frozen-members-resist-reassignment**: Once frozen, an assignment to a static method (`Uri.parse = ...`) or a prototype method (`Uri.prototype.toString = ...`) from extension code MUST leave the original function in place — in sloppy-mode code the assignment expression evaluates to the assigned value while the property itself is untouched; in strict-mode code the same assignment MUST throw `TypeError` instead — and in neither case is the underlying function replaced.
- **url-from-string**: Reading a URL from a JavaScript value MUST parse it as a URL from the string's own contents when the value is a plain string, and MUST answer nothing when that string cannot be turned into a URL.
- **url-from-uri-instance**: Reading a URL from a JavaScript value MUST, for a value that is an instance of the installed `Uri` constructor, read its `toString` property and invoke it through a guarded call — never an unguarded direct invocation that lets a thrown error escape uncaught — with no arguments, then parse the result as a URL only when that call succeeds and returns a string.
- **url-from-rejects-non-uri-non-string**: Reading a URL from a JavaScript value MUST return nothing, without reading any property off it, for a value that is neither a string nor an instance of the installed `Uri` constructor — including a number, a plain object shaped like a `Uri`, and JavaScript `undefined`.
- **url-from-swallows-to-string-failure**: Reading a URL from a JavaScript value MUST answer nothing — with no signal to its caller — when the value's `toString` property is absent or not callable, when the guarded call to it fails to settle successfully (it throws, or the call is unavailable), or when the returned value is not a JavaScript string.
- **uri-value-builds-via-parse**: Building a `vscode.Uri` value for a native URL MUST call `Uri.parse` directly (unguarded, since it is the installed class's own function, not extension-suppliable), passing the URL's absolute-string form and no `strict` argument, so the throwing branch of **parse-strict-requires-scheme** is never reached from this path.
- **uri-value-nil-when-class-or-parse-unavailable**: Building a `vscode.Uri` value MUST return nothing when installing the class fails, when the constructor's `parse` property is absent or not usable, or when the call's result is nothing, `undefined`, or `null`.
- **uri-value-round-trips-with-url-from**: For a native URL, reading a URL from the result of building a `vscode.Uri` value for it MUST return a URL whose absolute-string form equals the original's.
- **main-thread-confinement**: Installing the class, reading a URL from a JavaScript value, and building a `vscode.Uri` value MUST all run only on a single, consistent thread, because every JavaScript-side argument they take is tied to the environment that created it and is not safe to hand across threads.
