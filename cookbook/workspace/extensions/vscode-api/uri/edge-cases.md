
- **Null/empty input**: `Uri.parse('')` MUST produce a `Uri` with every field `''` and no authority, taking the non-strict path (**parse-non-strict-allows-schemeless**). `Uri.file('')` MUST still produce a leading `'/'` (**file-ensures-leading-slash**) since the empty string is not itself falsy-as-a-path in the encoding step. `with()` and `with({})` (no argument, or an empty object) MUST return a `Uri` equal in every field to the receiver, since no key of `change` has a value `!== undefined` (**with-overrides-only-given-fields**). `Uri.joinPath(base)` with zero appended segments MUST leave `path` unchanged (**join-path-empty-appended-is-unchanged**).
- **Boundary values**: not applicable — no member here constrains `path`, `scheme`, `authority`, `query`, `fragment`, or the number of `joinPath` segments to a minimum or maximum length or count; none is declared in the source.
- **Concurrent access**: not applicable to a `Uri` instance itself — it is frozen at construction (**instance-frozen**) and every accessor is a pure read (**readonly-accessors**), so there is nothing for two readers to race over. The class object itself is a different story — see **lazy-adoption-race** below, and **class-caching-write-best-effort** for the narrower, fully-specified case of the caching write itself failing (which produces two distinct-but-equally-real `Uri` classes, not a race between a real and a counterfeit one).
- **lazy-adoption-race**: the host installs the frozen `Uri` class eagerly, before any extension code runs. If that eager install failed or was skipped, the first installation call MUST adopt whatever object already occupies that class's cache slot, real or not, and building a `vscode.Uri` value MUST call that object's `parse` directly (**uri-value-builds-via-parse**), unguarded. An extension-supplied `parse` that throws therefore escapes to whatever handles an uncaught exception in this environment, rather than being returned to that caller. This is documented as the one accepted residual corner of the original defect, narrowed by the freeze rather than eliminated, and no test exercises it.
- **Error states**: when the function being invoked has no usable execution context, the guarded-call helper that reading a URL depends on (**url-from-uri-instance**) answers "unavailable," which that read's guard converts to a plain nothing with no further signal (**url-from-swallows-to-string-failure**) — this is the documented, deliberate shape of an unavailable call, not a swallowed error. `Uri.parse(value, true)` with no scheme throws a JavaScript `Error` rather than swallowing the failure (**parse-strict-requires-scheme**); that throw is not caught anywhere in this component itself, so it propagates to whatever handles an uncaught exception in this environment, per that caller's own contract.
- **Offline/disconnected state**: not applicable — this component performs no network or file-system I/O of its own; every member only builds or reads in-memory JavaScript/URL values already resident in a caller-supplied extension environment.
