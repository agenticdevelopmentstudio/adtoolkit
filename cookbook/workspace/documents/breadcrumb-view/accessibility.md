
- **Identifier**: Each crumb button carries the accessibility identifier `breadcrumb.crumb.<index>`, set from the crumb's zero-based position in the strip — an identifier for automation, not the label a screen reader announces.
- **Label**: The crumb button's accessibility label derives from its full title text. Middle-truncation changes only the rendered glyphs, not the underlying title, so a screen reader announces the complete crumb title even when the visible text is truncated.
- **Role**: Crumb buttons keep the platform's default "button" accessibility role; no custom role or trait is set. The chevron separators are images created with no accessibility description — a deliberate decorative marking, so a screen reader does not present them as a separate stop.
- **Assistive technology**: Rebuilding the strip replaces every crumb view whenever the open file changes, without posting an accessibility notification (such as a layout-changed or announcement notification) around that replacement. A screen-reader user tracking the strip is told the path changed only if the platform's own automatic detection of the view-tree change surfaces it; the source itself makes no explicit announcement.
- **Minimum tap target**: Not applicable: this component targets pointer and trackpad input, not touch. The source sets no minimum width or height on a crumb button — each button sizes to its (possibly truncated) title — and the source platform's design guidance does not mandate a minimum click-target dimension for inline chrome controls the way a touch platform mandates a touch-target minimum.
