
A control error's description returns hardcoded English strings with no localization; the accessibility-not-available text addresses the user.

| String Key | Default (en) | Context |
|-----------|-------------|---------|
| (none) | `No window found with CGWindowID <windowID>` | window-not-found error |
| (none) | `Accessibility not available for <app> (PID <pid>). Grant Accessibility permission in System Settings.` | accessibility-not-available error |
| (none) | `Failed to set <attribute>: AXError code <axError>` | attribute-set-failed error |
| (none) | `Failed to activate <app> (PID <pid>)` | activation-failed error |
