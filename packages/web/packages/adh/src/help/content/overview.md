# Overview

This is the help section for the Agentic Developer Hub.

**Hub Features** covers the hub itself: workspaces, personas, documents, projects, files, products and the people you work with. Each feature has a page on what it is, a page for each of its parts, a card on what an application can do with it, and a card on why it is built the way it is.

**REST API** lists every endpoint the hub serves, with its parameters, request and responses. You can try a call against your current session.

**MCP** explains how an AI agent uses the Model Context Protocol with the hub: what the server is, how to connect your client, and the tools it offers.

Select a topic from the list to begin.
